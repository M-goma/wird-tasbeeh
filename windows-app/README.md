# وِرد لسطح مكتب Windows

نسخة Windows تعمل في الخلفية من منطقة الإشعارات. تعرض بطاقة تذكير فوق نافذة البرنامج النشطة، وتختفي تلقائيًا بعد المدة المحددة. لا تحتاج إلى تأكيد «سبّحت».

- الفترة الافتراضية: كل ٥ دقائق.
- مدة العرض الافتراضية: ٣٠ ثانية.
- إعدادات قابلة للتعديل: الذكر، الفاصل، المدة، والتشغيل مع بدء Windows.
- يعمل دون اتصال ويحفظ إعداداته على الجهاز.

## التنبيه

يجب أن يكون الكمبيوتر مستيقظًا والبرنامج يعمل في الخلفية كي تظهر التذكيرات. عند تثبيت البرنامج يُضاف اختصار إلى قائمة Start وسطح المكتب والتشغيل التلقائي. يظهر التذكير فوق نوافذ Windows أثناء الاستخدام، لكنه لا يظهر فوق شاشة القفل أو قبل تسجيل الدخول.
